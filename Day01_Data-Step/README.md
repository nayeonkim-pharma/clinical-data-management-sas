# Day 01. SAS Studio & DATA STEP

## 학습 목표

SAS의 기본적인 데이터 처리 과정을 이해하고
DATA STEP을 활용하여 간단한 데이터셋을 생성한다.

## 실습 내용

- DATA STEP을 이용한 데이터셋 생성
- INPUT을 이용한 변수 정의
- DATALINES를 이용한 데이터 입력
- PROC PRINT를 이용한 데이터 확인

## 실습 데이터

Patient 데이터를 가정하여 ID, Age, Sex 변수를 생성했다.

## Clinical Data Management와의 연결

임상시험에서는 대상자의 정보를 구조화된 데이터 형태로 관리하고
데이터의 정확성과 일관성을 확인하는 과정이 필요하다.

이번 실습에서는 간단한 대상자 데이터를 직접 생성하고
SAS를 활용하여 데이터셋의 내용을 확인하는 기본 과정을 연습했다.

## Key Takeaway

SAS의 기본적인 데이터 처리 과정은
데이터셋을 생성하고 내용을 확인하는 것에서 시작한다.
