# Clinical Data Management & SAS Practice

제약·임상시험 분야의 Clinical Data Management(CDM) 직무를 준비하며
SAS Programming 기초와 임상시험 데이터 처리 및 검증을 실습한 기록입니다.

## 🎯 Learning Goals

- SAS Programming 기초 문법 및 데이터 처리 학습
- 임상시험 데이터의 구조와 특성 이해
- Subject / Visit / AE 데이터 처리 실습
- 결측값, 중복, 이상값 등 Data Validation 실습
- 데이터셋 간 결합 및 데이터 비교 실습
- SAE Reconciliation 개념을 SAS 실습과 연결

## 🧪 Clinical Data Practice

가상의 임상시험 데이터를 활용하여 다음과 같은 데이터 관리 과정을 실습합니다.

- Subject data review
- Visit data completeness check
- AE data review
- Missing data identification
- Duplicate data identification
- Invalid data identification
- Dataset comparison
- Dataset integration
